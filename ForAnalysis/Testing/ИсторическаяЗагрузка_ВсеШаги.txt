// =====================================================================================================
//
// ЗАЧЕМ
//   Перенос заявок на технологическое присоединение из старой базы (внешний источник КрымMySQL,
//   таблицы bid / cot / evt / gvt) в документы ЭЭ_ЗаявкаТП и связанные с ними объекты.
//   Раньше это были 4 отдельные обработки, которые запускались вручную в строгом порядке.
//   Здесь они собраны в один модуль. Обычный запуск — «Выполнить все шаги» (0 -> 1 -> 2 -> 3 по порядку).
//   Кнопки «Шаг 0» … «Шаг 3» — чтобы выполнить или повторить отдельный шаг, например после его падения.
//   «Шаг 0» только создаёт заявки и пишет CSV; «Шаг 1/2/3» берут заявки из выбранного CSV.
//
// КАКИЕ ЗАЯВКИ ОБРАБАТЫВАЮТСЯ
//   Шаг 0 создаёт новые заявки и возвращает их список (партию: BidID + ссылка на заявку).
//   Шаги 1–3 дополняют ТОЛЬКО заявки партии — ранее загруженные заявки не трогаются.
//   Партия (до ~20 000 строк) живёт только в памяти сервера, на форму и на клиент она не передаётся:
//   * «Выполнить все шаги» — партия передаётся от шага 0 к шагам 1–3 через временное хранилище
//     (на клиент уходит только её адрес);
//   * после шага 0 номера заявок партии сохраняются в CSV на компьютере пользователя, в каталог
//     из реквизита КаталогCSV (по одному номеру в строке, имя Заявки_шаг0_ГГГГММДД_ЧЧММСС.csv);
//   * кнопки «Шаг 1/2/3» просят выбрать этот CSV и восстанавливают партию по номерам из него
//     (заявки ищутся по ИБР_Основание = номер и источнику БазаMySQL).
//   При запуске шагов по одному порядок 1 -> 2 -> 3 соблюдает пользователь (см. ниже, почему он важен).
//
// ПОРЯДОК ШАГОВ И ПОЧЕМУ ИМЕННО ТАКОЙ
//
//   Шаг 0. Создание заявок                          (было: ШагЗаполненияЗаявки.txt)
//          bid, которых ещё нет в ЭЭ_ЗаявкаТП  ->  новые документы ЭЭ_ЗаявкаТП + статус.
//          Номер = BidID, Дата = Bid_Date, ИБР_Основание = BidID, ЗаявкаПолученаССайта = БазаMySQL,
//          мощности, вид присоединения, РЭС, МО, тип заявителя, пакет документов, статус заявки.
//          -> Первым: определяет партию, которую дополняют шаги 1–3.
//          После шага 0 номера созданных заявок сохраняются в CSV (см. СохранитьCSVНаКлиенте).
//
//   Шаг 1. Адреса, объекты присоединения, ЭПУ       (было: Шаг_1_ЭПУ_Адреса_ОП.txt)
//          Для каждой неаннулированной заявки партии: новый ИБР_Адреса (кадастр из КрымPG),
//          новый ЭЭ_ОбъектыПрисоединения, ЭЭ_ЭнергопринимающиеУстройства по каждой мощности.
//          В заявке: адрес, объект присоединения, мощности по категориям, этап, уровень
//          напряжения, телефон, категория надёжности, вид присоединения.
//          -> После шага 0: дополняет созданные заявки.
//          -> До шага 3: вид договора (УТП_Сервер.ВернутьВидДоговораТП_поЗаявке) определяется
//             по заявке, поэтому мощности и вид присоединения к шагу 3 должны быть окончательными.
//
//   Шаг 2. Данные исполнения заявки                 (было: Шаг_2_ИсполненияЗаявки.txt)
//          evt / gvt / cot  ->  документ УТП_ДанныеИсполненияЗаявкиТП (шапка + ТЧ Оплаты)
//          и обратная ссылка ЭЭ_ЗаявкаТП.ДанныеИсполненияЗаявки.
//          -> После шага 0: нужна заявка.
//          -> До шага 3: шаг 3 дописывает в этот документ ВыполненоКСелектору.
//
//   Шаг 3. Договоры и акты ТП                       (было: Шаг_3_Договоры_акты.txt)
//          bid.Dogovor_*       -> ИБР_Договоры                         (ЭЭ_ЗаявкаТП.ДоговорТП)
//          cot.RealAct_*       -> ЭЭ_АктОТехнологическомПрисоединении  (ЭЭ_ЗаявкаТП.АктОТехнологическомПрисоединении)
//          bid.SocTarif        -> ЭЭ_ЗаявкаТП.ЛьготнаяКатегория
//          evt.Vyp_k_Sel_Date  -> УТП_ДанныеИсполненияЗаявкиТП.ВыполненоКСелектору
//          -> Последним: использует результаты шагов 1 и 2.
//
// ОБЩЕЕ ДЛЯ ВСЕХ ШАГОВ
//   * Связь старой и новой базы: ЭЭ_ЗаявкаТП.ИБР_Основание = bid.BidID (оба Число).
//     Шаги 1–3 берут из партии и BidID (для запросов к КрымMySQL), и ссылку на заявку.
//   * Создать или обновить: если у заявки уже есть объект, который создаёт шаг (адрес, ОП, ЭПУ, данные
//     исполнения, договор, акт), он обновляется, а не создаётся заново. Поэтому любой шаг можно повторить
//     для той же партии без дублей. Шаг 0 создаёт только заявки, которых ещё нет; существующие не трогает.
//   * Объекты пишутся с ОбменДанными.Загрузка = Истина: ПередЗаписью / ОбработкаПроведения
//     и подписки не выполняются — данные исторические и уже готовы.
//   * В одном запросе нельзя соединять таблицы разных источников (ИБ, КрымMySQL, КрымPG):
//     «Получение данных из нескольких источников данных недопустимо». Поэтому каждый источник
//     выгружается отдельно и сопоставляется: временной таблицей в ИБ (шаг 0), в памяти по номеру
//     заявки (шаг 1), списком BidID в тексте запроса к MySQL (шаги 1–3, см. ВыполнитьЗапросКрымMySQLПорциями).
//   * Список BidID партии (20 000+) в запрос к КрымMySQL целиком не передаётся: длинное «В (...)» MySQL не
//     выдерживает. Запросы идут порциями по РазмерПорцииКрымMySQL() (50). Запросы к ИБ со списком заявок
//     («Ссылка В (&СписокЗаявок)») не режутся: 1С сама передаёт большой список в СУБД через временную таблицу.
//   * Ошибка по одной заявке не останавливает шаг: пишется в журнал регистрации, шаг идёт дальше.
//     Если шаг упал целиком (нет связи с КрымMySQL, не найден обязательный элемент справочника),
//     выполнение останавливается: следующие шаги зависят от предыдущих.
//   * В начале и в конце каждого шага выводится сообщение с итогами.
//
// ЧТО НУЖНО СОЗДАТЬ НА ФОРМЕ
//   Реквизит:
//     КаталогCSV - Строка(0) - каталог на компьютере пользователя для CSV шага 0 (без него шаг 0 не запускается).
//   Команды (действие — одноимённая процедура &НаКлиенте):
//     ВыбратьКаталогCSV - выбор каталога для CSV в реквизит КаталогCSV;
//     ВыполнитьВсеШаги - шаги 0 -> 1 -> 2 -> 3;
//     ВыполнитьШаг0 - только создание заявок + CSV с их номерами;
//     ВыполнитьШаг1, ВыполнитьШаг2, ВыполнитьШаг3 - один шаг по заявкам из выбранного CSV шага 0.
//
// =====================================================================================================

// Контекст шага 1: заполняется в Шаг1_ПерегрузитьАдресаЗаявок, читается в Шаг1_ОбработатьЗаявку.
&НаСервере

// CSV из временного хранилища -> файл КаталогCSV\Заявки_шаг0_ГГГГММДД_ЧЧММСС.csv на компьютере пользователя.
// Сохранение асинхронное; продолжение (сообщение и, для «Выполнить все шаги», шаги 1–3) — в ПослеСохраненияCSV.
&НаКлиенте
Процедура СохранитьCSVНаКлиенте(Результат, ПродолжитьШаги)

	ПередаваемыеФайлы = Новый Массив;
	ПередаваемыеФайлы.Добавить(Новый ОписаниеПередаваемогоФайла(Результат.ИмяФайла, Результат.АдресCSV));

	Параметры = Новый Структура("Результат, ПродолжитьШаги", Результат, ПродолжитьШаги);
	Оповещение = Новый ОписаниеОповещения("ПослеСохраненияCSV", ЭтотОбъект, Параметры);
	Попытка
		НачатьПолучениеФайлов(Оповещение, ПередаваемыеФайлы, КаталогCSV, Ложь);
	Исключение
		Сообщить("Ошибка сохранения CSV: " + КраткоеПредставлениеОшибки(ИнформацияОбОшибке()));
		ВыполнитьОбработкуОповещения(Оповещение, Неопределено);
	КонецПопытки;

КонецПроцедуры

// Даже если CSV не сохранился, шаги 1–3 выполняются: заявки уже созданы, и дополнить их нужно в любом случае.
&НаКлиенте
Процедура ПослеСохраненияCSV(ПолученныеФайлы, Параметры) Экспорт

	Если ПолученныеФайлы <> Неопределено И ПолученныеФайлы.Количество() > 0 Тогда
		Сообщить("Номера созданных заявок (" + Параметры.Результат.Количество + ") записаны в файл: " + ПолученныеФайлы[0].Имя);
	Иначе
		Сообщить("CSV с номерами заявок НЕ сохранён в каталог " + КаталогCSV
			+ ". Проверьте, что каталог существует и доступен для записи.");
	КонецЕсли;

	Если Параметры.ПродолжитьШаги Тогда
		ВыполнитьШаги1_3НаСервере(Параметры.Результат.АдресПартии);
	КонецЕсли;

КонецПроцедуры

// Выбор CSV шага 0 и передача его на сервер. Диалог асинхронный (модальные окна в новых платформах запрещены):
// файл помещается во временное хранилище, дальше работа идёт в ПослеВыбораCSV.

	Диалог.Заголовок = "Шаг " + НомерШага + ": выберите CSV с номерами заявок шага 0";
	Диалог.Фильтр = "Номера заявок шага 0 (*.csv)|*.csv";
	Диалог.МножественныйВыбор = Ложь;
	Диалог.Каталог = КаталогCSV;

	Оповещение = Новый ОписаниеОповещения("ПослеВыбораCSV", ЭтотОбъект, НомерШага);
	НачатьПомещениеФайла(Оповещение, , Диалог, Истина, УникальныйИдентификатор);

КонецПроцедуры

&НаКлиенте
Процедура ПослеВыбораCSV(Выбран, Адрес, ВыбранноеИмяФайла, НомерШага) Экспорт

	Если Не Выбран Тогда
		Возврат; // пользователь отменил выбор файла
	КонецЕсли;
	ВыполнитьШагПоCSVНаСервере(НомерШага, Адрес, ВыбранноеИмяФайла);

// Шаг 0 на сервере. Возвращает Неопределено, если шаг прерван или не создал ни одной заявки,
// иначе Структуру для клиента: Количество, ИмяФайла, АдресCSV (файл во временном хранилище),
// АдресПартии (партия во временном хранилище — только если СохранитьПартию, для шагов 1–3).
// Сама партия (до ~20 000 строк) на клиент не передаётся: клиент получает только адреса.
&НаСервере
Функция ВыполнитьШаг0НаСервере(СохранитьПартию)

	Партия = Неопределено;
	Если Не ВыполнитьШаг(0, Партия) Тогда
		Сообщить("Выполнение остановлено на шаге 0. Шаги 1–3 не запускались.");
		Возврат Неопределено;
	КонецЕсли;

	Если Партия.Количество() = 0 Тогда
		Сообщить("Шаг 0 не создал ни одной заявки — CSV не сохраняется, шагам 1–3 нечего дополнять.");
		Возврат Неопределено;
	КонецЕсли;

	Результат = Новый Структура;
	Результат.Вставить("Количество",  Партия.Количество());
	Результат.Вставить("ИмяФайла",    "Заявки_шаг0_" + Формат(ТекущаяДатаСеанса(), "ДФ=yyyyMMdd_HHmmss") + ".csv");
	Результат.Вставить("АдресCSV",    CSVПартииВоВременноеХранилище(Партия));
	Результат.Вставить("АдресПартии", ?(СохранитьПартию, ПоместитьВоВременноеХранилище(Партия, УникальныйИдентификатор), ""));
	Возврат Результат;

КонецФункции

// Шаги 1 -> 2 -> 3 по партии шага 0 (для «Выполнить все шаги»).
// Если шаг прерван целиком — дальше не идём: следующие шаги опираются на его результат.
&НаСервере
Процедура ВыполнитьШаги1_3НаСервере(АдресПартии)

	Партия = ПолучитьИзВременногоХранилища(АдресПартии);
	УдалитьИзВременногоХранилища(АдресПартии);

	Для НомерШага = 1 По 3 Цикл
		Если Не ВыполнитьШаг(НомерШага, Партия) Тогда
			Сообщить("Выполнение остановлено на шаге " + НомерШага + ". Следующие шаги не запускались.");
			Возврат;
		КонецЕсли;
	КонецЦикла;

	Сообщить("Все шаги выполнены. Заявок в партии: " + Партия.Количество() + ".");

КонецПроцедуры

// Запускает один шаг с сообщениями о начале/конце и временем выполнения.
// Для шага 0 Партия — возвращаемый параметр, для шагов 1–3 — входной.
// Возвращает Ложь, если шаг прерван исключением (ошибки по отдельным заявкам шаг обрабатывает сам).
&НаСервере
Функция ВыполнитьШаг(НомерШага, Партия)

	Названия = Новый Массив;
	Названия.Добавить("Создание заявок");
	Названия.Добавить("Адреса, объекты присоединения, ЭПУ");
	Названия.Добавить("Данные исполнения заявки");
	Названия.Добавить("Договоры и акты ТП");

	Заголовок = "Шаг " + НомерШага + ". " + Названия[НомерШага];
	Сообщить("===== " + Заголовок + ": начало " + Формат(ТекущаяДатаСеанса(), "ДЛФ=T"));
	Начало = ТекущаяУниверсальнаяДатаВМиллисекундах();

	Попытка
		Если НомерШага = 0 Тогда
			Партия = Шаг0_СоздатьЗаявки();
		ИначеЕсли НомерШага = 1 Тогда
			Шаг1_ПерегрузитьАдресаЗаявок(Партия);
		ИначеЕсли НомерШага = 2 Тогда
			Шаг2_ЗагрузитьДанныеИсполнения(Партия);
		ИначеЕсли НомерШага = 3 Тогда
			Шаг3_ЗагрузитьДоговорыИАкты(Партия);
		КонецЕсли;
	Исключение
		Сообщить("===== " + Заголовок + ": ПРЕРВАН. " + КраткоеПредставлениеОшибки(ИнформацияОбОшибке()));

			Иначе

			ЗаполнитьСписокДокументов(ЗаявкаОб);

			ЗаявкаОб.Номер = Выборка.BidID;
			ЗаявкаОб.ЗаявкаПолученаССайта = Справочники.УТП_ИсточникиЗаявок.БазаMySQL; // второй ключ связи

			// Кто и когда создал заявку (при Загрузка = Истина обработчики записи их не заполнят).
			ЗаявкаОб.ИБР_ДатаСоздания    = ТекущаяДата();
			ЗаявкаОб.ИБР_Автор           = ПараметрыСеанса.ИБР_ТекущийПользователь;
			ЗаявкаОб.ИБР_ДолжностноеЛицо = ПараметрыСеанса.ИБР_ДолжностьПользователяПоУмолчанию;

			ЗаявкаОб.ОбменДанными.Загрузка = Истина;
			ЗаявкаОб.Записать();

			// В партию — сразу после записи: даже если статус ниже не установится, заявка уже есть в базе,
			// повторный шаг 0 её не создаст, и дополнить её могут только шаги 1–3 этого запуска.
			НоваяСтрока = Партия.Добавить();
			НоваяСтрока.BidID  = Выборка.BidID;
			НоваяСтрока.Заявка = ЗаявкаОб.Ссылка;

			// Статус заявки — по самому «продвинутому» состоянию в bid/cot:
			// аннулирована > есть акт > договор подписан > договор направлен > черновик.
			Если ЗначениеЗаполнено(Выборка.Annul_Date) ИЛИ ЗначениеЗаполнено(Выборка.Annul_NN) Тогда
				УстанавливаемыйСтатус = Справочники.ИБР_Статусы.НайтиПоКоду("000000043"); // архив аннулировано
			ИначеЕсли ЗначениеЗаполнено(Выборка.RealAct_NN) ИЛИ ЗначениеЗаполнено(Выборка.RealAct_Date) Тогда

// КрымMySQL.bid -> ИБР_Адреса -> ЭЭ_ОбъектыПрисоединения
//               -> ЭЭ_ЭнергопринимающиеУстройства (по одному на каждую заполненную мощность)
//               -> ЭЭ_ЗаявкаТП: АдресПодключения, ОбъектПрисоединения, мощности по категориям, этап,
//                  УровеньНапряжения, Телефон (из bid.Obj_Phone, только если заполнен), вид присоединения.
// Обрабатываются только заявки партии (созданные шагом 0): bid читаются по их BidID.
// Кадастр берётся из КрымPG (privatecab_public_orders) по связи utp_number = BidID.
// Аннулированные заявки (в bid заполнен Annul_NN или Annul_Date) не обрабатываются: адрес/ОП/ЭПУ им не нужны.
// Каждая заявка пишется в своей транзакции: адрес, ОП, ЭПУ и заявка — либо все, либо ничего.
// Ошибки и пропуски — в журнал «ИсторическиеЗаявки. Подготовка адреса».
//
//
// СОЗДАТЬ ИЛИ ОБНОВИТЬ (шаг можно безопасно повторять):
//   * адрес — если в заявке уже есть АдресПодключения, обновляется он, иначе создаётся новый;
//   * объект присоединения — если в заявке уже есть ОбъектПрисоединения, обновляется он, иначе создаётся;
//   * ЭПУ — у существующего ОП ищутся его ЭПУ по паре «категория надёжности + подключаемое/ранее
//     присоединённое» (подключаемое = ЭПУ со ссылкой на заявку). Найдено — обновляется, нет — создаётся.
//     ЭПУ, для которых в bid больше нет мощности, помечаются на удаление.

Процедура Шаг1_ОбработатьЗаявку(СтрокаBID)

		Шаг1_ЗаписатьОшибку(НомерЗаявки, Заявка, "Значение """ + НапряжениеBID + """ нет в соответствии - уровень напряжения пустой",
			УровеньЖурналаРегистрации.Предупреждение);
	КонецЕсли;

	// Мощности для объекта присоединения: полная (Sum) и ранее присоединённая (Cur) по категориям.
	Мощности = Новый Структура;

	Мощности.Вставить("Категория2",      ЧислоИлиНоль(СтрокаBID.Bid_PowerSum2));
	Мощности.Вставить("Категория3",      ЧислоИлиНоль(СтрокаBID.Bid_PowerSum3));
	Мощности.Вставить("РанееКатегория1", ЧислоИлиНоль(СтрокаBID.Bid_PowerCur1));
	Мощности.Вставить("РанееКатегория2", ЧислоИлиНоль(СтрокаBID.Bid_PowerCur2));
	Мощности.Вставить("РанееКатегория3", ЧислоИлиНоль(СтрокаBID.Bid_PowerCur3));

	// Мощности для заявки: полная по категориям и прирост (Sum - Cur) по категориям.
	Мощности_заяв = Новый Структура;
	Мощности_заяв.Вставить("ПолнаяКатегория1", ЧислоИлиНоль(СтрокаBID.Bid_PowerSum1));
	Мощности_заяв.Вставить("ПолнаяКатегория2", ЧислоИлиНоль(СтрокаBID.Bid_PowerSum2));
	Мощности_заяв.Вставить("ПолнаяКатегория3", ЧислоИлиНоль(СтрокаBID.Bid_PowerSum3));
	Мощности_заяв.Вставить("Категория1", ЧислоИлиНоль(СтрокаBID.Bid_PowerSum1) - ЧислоИлиНоль(СтрокаBID.Bid_PowerCur1));
	Мощности_заяв.Вставить("Категория2", ЧислоИлиНоль(СтрокаBID.Bid_PowerSum2) - ЧислоИлиНоль(СтрокаBID.Bid_PowerCur2));
	Мощности_заяв.Вставить("Категория3", ЧислоИлиНоль(СтрокаBID.Bid_PowerSum3) - ЧислоИлиНоль(СтрокаBID.Bid_PowerCur3));

	ОписанияЭПУ_Мс = Шаг1_ОписанияЭПУ(СтрокаBID, НаименованиеОП);

	// --- запись: адрес -> ОП -> ЭПУ -> заявка, одной транзакцией ---

	НачатьТранзакцию();
	Попытка

		// Заявка читается первой: в ней ссылки на адрес и ОП, если они уже были созданы.
		ДокОбъект = Заявка.ПолучитьОбъект();
		ЕстьАдрес = ЗначениеЗаполнено(ДокОбъект.АдресПодключения);
		ЕстьОП    = ЗначениеЗаполнено(ДокОбъект.ОбъектПрисоединения);

		// Адрес: есть в заявке — обновляем, нет — создаём.
		Если ЕстьАдрес Тогда
			АдресОбъект = ДокОбъект.АдресПодключения.ПолучитьОбъект();
		Иначе
			АдресОбъект = Справочники.ИБР_Адреса.СоздатьЭлемент();
		КонецЕсли;
		АдресОбъект.Наименование            = Адрес;
		АдресОбъект.АдресПредставление      = Адрес;
		АдресОбъект.КадастровыйНомерУчастка = ?(Кадастр = Неопределено, "", Кадастр);
		АдресОбъект.ИБР_Основание           = СтрокаBID.BidID;
		АдресОбъект.ОбменДанными.Загрузка = Истина;
		АдресОбъект.Записать();

		// Объект присоединения (ссылается на адрес): есть в заявке — обновляем, нет — создаём.
		Если ЕстьОП Тогда
			ОПОбъект = ДокОбъект.ОбъектПрисоединения.ПолучитьОбъект();
		Иначе
			ОПОбъект = Справочники.ЭЭ_ОбъектыПрисоединения.СоздатьЭлемент();
		КонецЕсли;
		ОПОбъект.Наименование = НаименованиеОП;
		ОПОбъект.Адрес        = АдресОбъект.Ссылка;
		ЗаполнитьЗначенияСвойств(ОПОбъект, Мощности);
		ОПОбъект.РанееРазрешеннаяМощность = ОПОбъект.РанееКатегория1 + ОПОбъект.РанееКатегория2 + ОПОбъект.РанееКатегория3;
		ОПОбъект.УровеньНапряжения = УровеньНапряжения;
		ОПОбъект.ИБР_Основание     = СтрокаBID.BidID;
		ОПОбъект.ОбменДанными.Загрузка = Истина;
		ОПОбъект.Записать();

		// ЭПУ (владелец — объект присоединения; подключаемые ЭПУ ссылаются на заявку).
		// У нового ОП ЭПУ ещё нет; у существующего — берём его ЭПУ и сопоставляем по ключу.
		СуществующиеЭПУ = ?(ЕстьОП, Шаг1_СуществующиеЭПУ(ОПОбъект.Ссылка), Новый Соответствие);
		Для Каждого ЭПУ Из ОписанияЭПУ_Мс Цикл
			КлючЭПУ = Шаг1_КлючЭПУ(ЭПУ.Подключаемая, ЭПУ.Категория);
			СсылкаЭПУ = СуществующиеЭПУ[КлючЭПУ];
			Если СсылкаЭПУ <> Неопределено Тогда
				ЭПУОбъект = СсылкаЭПУ.ПолучитьОбъект();
				СуществующиеЭПУ.Удалить(КлючЭПУ); // сопоставлено — не удалять ниже
			Иначе
				ЭПУОбъект = Справочники.ЭЭ_ЭнергопринимающиеУстройства.СоздатьЭлемент();
			КонецЕсли;
			ЭПУОбъект.Владелец            = ОПОбъект.Ссылка;
			ЭПУОбъект.Наименование        = ЭПУ.Наименование;
			ЭПУОбъект.Мощность            = ЭПУ.Мощность;
			ЭПУОбъект.КатегорияНадежности = ЭПУ.Категория;
			ЭПУОбъект.УровеньНапряжения   = УровеньНапряжения;
			Если ЭПУ.Подключаемая Тогда
				ЭПУОбъект.Заявка = Заявка;
			КонецЕсли;
			ЭПУОбъект.ИБР_Основание = СтрокаBID.BidID;
			ЭПУОбъект.ОбменДанными.Загрузка = Истина;
			ЭПУОбъект.Записать();
		КонецЦикла;

		// Оставшиеся ЭПУ существующего ОП в bid больше не встречаются (мощность стала 0) — на удаление.
		Для Каждого КлючИЗначение Из СуществующиеЭПУ Цикл
			ЭПУОбъект = КлючИЗначение.Значение.ПолучитьОбъект();
			ЭПУОбъект.ПометкаУдаления = Истина;
			ЭПУОбъект.ОбменДанными.Загрузка = Истина;
			ЭПУОбъект.Записать();
		КонецЦикла;

		// Заявка (объект получен в начале транзакции). Этапы пересобираются заново.
		ДокОбъект.Этапы.Очистить();

		ДокОбъект.АдресПодключения    = АдресОбъект.Ссылка;
		ДокОбъект.ОбъектПрисоединения = ОПОбъект.Ссылка;
		ЗаполнитьЗначенияСвойств(ДокОбъект, Мощности_заяв);
		ДокОбъект.ЕдиновременнаяНагрузка = Мощности_заяв.ПолнаяКатегория1 + Мощности_заяв.ПолнаяКатегория2 + Мощности_заяв.ПолнаяКатегория3;

		ДокОбъект.УровеньНапряжения = УровеньНапряжения;
		Если ЗначениеЗаполнено(ТелефонBID) Тогда
			ДокОбъект.Телефон = ТелефонBID;
		КонецЕсли;

		ДокОбъект.МощностьПоКатегориямНадежности = ""
			+ ?(ДокОбъект.Категория1 > 0, "первая (" + ДокОбъект.Категория1 + "кВт), ", "")
			+ ?(ДокОбъект.Категория2 > 0, "вторая (" + ДокОбъект.Категория2 + "кВт), ", "")
			+ ?(ДокОбъект.Категория3 > 0, "третья (" + ДокОбъект.Категория3 + "кВт) ", "");

		// Один этап «Полное подключение» на всю мощность (этапы очищены выше, итог = 0).
		МощностьЭтапа = ДокОбъект.ЕдиновременнаяНагрузка - ДокОбъект.Этапы.Итог("Мощность");
		Если МощностьЭтапа > 0 Тогда
			НЭ = ДокОбъект.Этапы.Добавить();
			НЭ.НазваниеЭтапа = "Полное подключение";
			НЭ.Мощность   = МощностьЭтапа;
			НЭ.Категория1 = ДокОбъект.Категория1 - ДокОбъект.Этапы.Итог("Категория1");
			НЭ.Категория2 = ДокОбъект.Категория2 - ДокОбъект.Этапы.Итог("Категория2");
			НЭ.Категория3 = ДокОбъект.Категория3 - ДокОбъект.Этапы.Итог("Категория3");
		КонецЕсли;

		// Категория надёжности заявки — самая высокая из заполненных.
		ДокОбъект.КатегорияНадежности = ?(ДокОбъект.ПолнаяКатегория1 > 0, Справочники.ЭЭ_КатегорииНадежности.Категория1,
			?(ДокОбъект.ПолнаяКатегория2 > 0, Справочники.ЭЭ_КатегорииНадежности.Категория2, Справочники.ЭЭ_КатегорииНадежности.Категория3));
		ДокОбъект.ПолнаяМощность = ДокОбъект.ОбъектПрисоединения.РанееРазрешеннаяМощность + ДокОбъект.ЕдиновременнаяНагрузка;

		Для Каждого ТекЭтап Из ДокОбъект.Этапы Цикл
			ТекЭтап.СписокКатегорий = "" + ?(ТекЭтап.Категория1 > 0, "1,", "") + ?(ТекЭтап.Категория2 > 0, " 2,", "") + ?(ТекЭтап.Категория3 > 0, " 3", "");
		КонецЦикла;

		// Вид присоединения — окончательно, по объекту присоединения (на шаге 0 был предварительный).
		ДокОбъект.НаУвеличениеМощности   = (ДокОбъект.ОбъектПрисоединения.РанееРазрешеннаяМощность > 0);
		ДокОбъект.ВидообразующийРеквизит = ?(ДокОбъект.НаУвеличениеМощности,
			Справочники.ИБР_ВидыОбъектов.Увеличение, Справочники.ИБР_ВидыОбъектов.ПервичноеПрисоединение);

		ДокОбъект.ОбменДанными.Загрузка = Истина;
		ДокОбъект.Записать();

		ЗафиксироватьТранзакцию();
		КонтекстШага1.Обработано = КонтекстШага1.Обработано + 1;
		Если ЕстьАдрес ИЛИ ЕстьОП Тогда
			КонтекстШага1.Обновлено = КонтекстШага1.Обновлено + 1;
		КонецЕсли;

	Исключение

		ОтменитьТранзакцию();
		Шаг1_ЗаписатьОшибку(НомерЗаявки, Заявка, ПодробноеПредставлениеОшибки(ИнформацияОбОшибке()));
		КонтекстШага1.Ошибок = КонтекстШага1.Ошибок + 1;

	КонецПопытки;

#Область Шаг2_ДанныеИсполненияЗаявки
// =====================================================================================================
// Загрузка данных исполнения заявок из КрымMySQL в документы УТП_ДанныеИсполненияЗаявкиТП.
//
// Схема связей:
//   ЭЭ_ЗаявкаТП.ИБР_Основание = bid.BidID          (заявки с ЗаявкаПолученаССайта = БазаMySQL)
//   ЭЭ_ЗаявкаТП.Ссылка = УТП_ДанныеИсполненияЗаявкиТП.ЗаявкаТП
//   bid ─(BidID)─ evt / gvt / cot (1:1), bid.IstFinID → istfin
//
// Временная таблица из ВременаяТаблицаЗапроса лежит в ИБ, и запрос к КрымMySQL её не видит.
// Поэтому связь ИБ ↔ MySQL — через список BidID, подставленный прямо в текст запроса к MySQL
// (параметр-массив 1С передаёт в MySQL через временную таблицу, а права CREATE TEMPORARY TABLES у onec нет).
//
// Порядок:
//   1. Запрос к ИБ: заявки партии (шаг 0) + уже существующие по ним документы данных исполнения.
//   2. Пакетный запрос к КрымMySQL порциями по РазмерПорцииКрымMySQL() BidID: [0] шапка, [1] ТЧ Оплаты.
//   3. Шапка — одним ЗаполнитьЗначенияСвойств; ЗаявкаТП — из строки ИБ того же BidID;
//      ВидообразующийРеквизит — «Данные для отчёта». Существующий документ обновляется, иначе создаётся.
//   4. Запись: Проведен = Истина + ОбменДанными.Загрузка = Истина — документ помечен проведённым,
//      но ОбработкаПроведения / ПередЗаписью / подписки не выполняются.
//      В заявке проставляется обратная ссылка ДанныеИсполненияЗаявки (только если изменилась).
// Повторный запуск безопасен: обновляет те же документы, новых не плодит.
//
// Параметры:
//   Партия               - ТаблицаЗначений (BidID, Заявка) - заявки, созданные шагом 0.
//   ДелительТысРуб      - Число - 1 или 1000. Пересчёт единиц для 5 реквизитов, у которых в синониме 1С «тыс.руб»:
//                                  ПервичнаяСтоимостьПИР <- evt.PirBase_Sum,  СуммаДоговораПИР <- evt.PirDog_Sum,
//                                  СметнаяСтоимостьПроекта <- evt.ProeSmeta_Sum, СтоимостьОсновныхФондов <- evt.OsnFond_Sum,
//                                  ВыпадающиеРасходы <- evt.Others_Sum.
//                                  В TPrLog единицы этих полей MySQL не указаны. Если в MySQL рубли, а в 1С тыс.руб,
//                                  без деления значение будет в 1000 раз больше.
//                                  Пример: evt.PirBase_Sum = 1250000 -> при 1000: 1 250,00; при 1: 1 250 000,00.
//                                  Как выбрать: сверить 2-3 заявки с известной суммой ПИР/сметы.
//                                  Остальные суммы (ГКЦТ, КУэ, подряд, акт ПИР) в 1С в рублях и не делятся.
&НаСервере
Процедура Шаг2_ЗагрузитьДанныеИсполнения(Партия, ДелительТысРуб = 1)

	РазмерПорции = РазмерПорцииКрымMySQL(); // пакет [шапка + оплаты] — свой цикл порций, размер общий

	Создано = 0; Обновлено = 0; Ошибок = 0;

	// Вид документа — один раз на всю загрузку. Не найден — исключение, шаг прерывается.
	ВидОбъектаУТП = Шаг2_ВидДанныхДляОтчета();

	// 1. Заявки партии и их документы данных исполнения (если уже есть)
	ЗаявкиИБ_тз = Шаг2_ЗаявкиИБ(Партия.ВыгрузитьКолонку("Заявка"));
	Сообщить("Заявок партии к обработке: " + ЗаявкиИБ_тз.Количество());

	// BidID -> строка ЗаявкиИБ_тз. ТаблицаЗначений.Найти() каждый раз просматривает таблицу целиком
	// (200 000 × 200 000); Соответствие.Получить() — мгновенно.
	ЗаявкиПоBidID = Новый Соответствие;
	Для Каждого СтрокаИБ Из ЗаявкиИБ_тз Цикл
		ЗаявкиПоBidID.Вставить(СтрокаИБ.BidID, СтрокаИБ);
	КонецЦикла;

	// 2. Запрос к КрымMySQL — порциями по списку BidID
	ТекстЗапросаMySQL = Шаг2_ТекстЗапросаКрымMySQL(); // шаблон: &СписокBidID заменяется кодами для каждой порции
	Запрос = Новый Запрос;
	Запрос.УстановитьПараметр("ДелительТысРуб", ДелительТысРуб);

	ВсеBidID = ЗаявкиИБ_тз.ВыгрузитьКолонку("BidID");
	Начало = 0;
	Пока Начало < ВсеBidID.Количество() Цикл

		СписокBidID = Новый Массив;
		Для Индекс = Начало По Мин(Начало + РазмерПорции, ВсеBidID.Количество()) - 1 Цикл
			СписокBidID.Добавить(Формат(ВсеBidID[Индекс], "ЧГ=0; ЧН=0"));
		КонецЦикла;
		Начало = Начало + РазмерПорции;

		Запрос.Текст = СтрЗаменить(ТекстЗапросаMySQL, "&СписокBidID", СтрСоединить(СписокBidID, ", "));
		Пакет = Запрос.ВыполнитьПакет();

		ВыборкаШапка = Пакет[0].Выбрать();
		Оплаты_тз = Пакет[1].Выгрузить();
		Оплаты_тз.Индексы.Добавить("Источник_BidID");

		// 3. Заполнение документов
		Пока ВыборкаШапка.Следующий() Цикл
			СтрокаИБ = ЗаявкиПоBidID.Получить(ВыборкаШапка.BIDID_ЗаявкаТП);
			Если СтрокаИБ = Неопределено Тогда
				Продолжить;
			КонецЕсли;
			Попытка
				// Существующий документ: найденный по ЗаявкаТП, а если такого нет — указанный в самой заявке.
				СуществующийДокумент = ?(ЗначениеЗаполнено(СтрокаИБ.ДанныеИсполнения),
					СтрокаИБ.ДанныеИсполнения, СтрокаИБ.ДанныеИсполненияВЗаявке);
				ЭтоНовыйДокумент = Не ЗначениеЗаполнено(СуществующийДокумент);
				Если ЭтоНовыйДокумент Тогда
					ДанныеИсполнения_об = Документы.УТП_ДанныеИсполненияЗаявкиТП.СоздатьДокумент();
					ДанныеИсполнения_об.Дата = ТекущаяДатаСеанса();
				Иначе
					ДанныеИсполнения_об = СуществующийДокумент.ПолучитьОбъект();
				КонецЕсли;

				// Шапка. Поля Источник_* и BIDID_ЗаявкаТП в документе отсутствуют и пропускаются.
				ЗаполнитьЗначенияСвойств(ДанныеИсполнения_об, ВыборкаШапка);
				ДанныеИсполнения_об.ЗаявкаТП = СтрокаИБ.Заявка;
				ДанныеИсполнения_об.ВидообразующийРеквизит = ВидОбъектаУТП;

				// ТЧ Оплаты — полностью из cot
				ДанныеИсполнения_об.Оплаты.Очистить();
				Для Каждого СтрокаОплаты Из Оплаты_тз.НайтиСтроки(Новый Структура("Источник_BidID", ВыборкаШапка.BIDID_ЗаявкаТП)) Цикл
					ЗаполнитьЗначенияСвойств(ДанныеИсполнения_об.Оплаты.Добавить(), СтрокаОплаты);
				КонецЦикла;

				// 4. Запись в режиме загрузки + пометка проведения
				ДанныеИсполнения_об.Проведен = Истина;
				ДанныеИсполнения_об.ИБР_Основание = ВыборкаШапка.BIDID_ЗаявкаТП; // = ЭЭ_ЗаявкаТП.ИБР_Основание (BidID)
				ДанныеИсполнения_об.ОбменДанными.Загрузка = Истина;
				Если ДанныеИсполнения_об.ЭтоНовый() И Не ЗначениеЗаполнено(ДанныеИсполнения_об.Номер) Тогда
					ДанныеИсполнения_об.УстановитьНовыйНомер();
				КонецЕсли;
				// Кто и когда создал — только у нового документа, у существующего не перетираем.
				Если ЭтоНовыйДокумент Тогда
					ДанныеИсполнения_об.ИБР_Автор = ПараметрыСеанса.ИБР_ТекущийПользователь;
					ДанныеИсполнения_об.ИБР_ДатаСоздания = ТекущаяДата();
					ДанныеИсполнения_об.ИБР_ДолжностноеЛицо = ПараметрыСеанса.ИБР_ДолжностьПользователяПоУмолчанию;
				КонецЕсли;
				ДанныеИсполнения_об.Записать();

				// Обратная ссылка в заявке — только если изменилась
				// (при повторной загрузке она уже стоит, и лишние 200 000 записей заявок не нужны)
				Если СтрокаИБ.ДанныеИсполненияВЗаявке <> ДанныеИсполнения_об.Ссылка Тогда
					ЭЭ_ЗаявкаТП_об = СтрокаИБ.Заявка.ПолучитьОбъект();
					ЭЭ_ЗаявкаТП_об.ДанныеИсполненияЗаявки = ДанныеИсполнения_об.Ссылка;
					ЭЭ_ЗаявкаТП_об.ОбменДанными.Загрузка = Истина;
					ЭЭ_ЗаявкаТП_об.Записать();
				КонецЕсли;

				Если ЭтоНовыйДокумент Тогда
					Создано = Создано + 1;
				Иначе
					Обновлено = Обновлено + 1;
				КонецЕсли;
			Исключение
				Ошибок = Ошибок + 1;
				ЗаписьЖурналаРегистрации("ИсторическиеЗаявки. Данные исполнения", УровеньЖурналаРегистрации.Ошибка,
					Метаданные.Документы.ЭЭ_ЗаявкаТП, СтрокаИБ.Заявка,
					"BidID " + Формат(ВыборкаШапка.BIDID_ЗаявкаТП, "ЧГ=0") + ": " + ПодробноеПредставлениеОшибки(ИнформацияОбОшибке()));
			КонецПопытки;
		КонецЦикла;

	КонецЦикла;


	Сообщить("Данные исполнения: создано " + Создано + ", обновлено " + Обновлено + ", ошибок " + Ошибок
		+ " (подробности — журнал ""ИсторическиеЗаявки. Данные исполнения"")");

// Элемент ИБР_ВидыОбъектов «Данные для отчёта» для документа «Данные исполнения заявки ТП».

// По каждой заявке партии (bid читаются по BidID заявок, созданных шагом 0):
//   * ЭЭ_ЗаявкаТП.ЛьготнаяКатегория — по bid.SocTarif (> 0 — льготная категория, иначе пусто);
//   * УТП_ДанныеИсполненияЗаявкиТП.ВыполненоКСелектору — по evt.Vyp_k_Sel_Date (документ создан на шаге 2);
//   * договор ТП (ИБР_Договоры): есть Dogovor_NN или Dogovor_Date — обновить договор из ЭЭ_ЗаявкаТП.ДоговорТП,
//     а если его нет — создать;
//     срок = Dogovor_Date + EvtSrok дней; нет — удалить ранее созданный;
//   * акт ТП (ЭЭ_АктОТехнологическомПрисоединении): есть RealAct_NN или RealAct_Date — обновить акт из
//     ЭЭ_ЗаявкаТП.АктОТехнологическомПрисоединении, а если его нет — создать
//     (дата акта — RealAct_Date, а если её нет — дата окончания договора); нет — удалить ранее созданный.
//     (Для новых заявок шага 0 договора и акта ещё нет, так что удаление срабатывает только при повторном запуске.)
// Заявка берётся из партии по BidID.
//
// В исходной обработке был отбор «есть номер акта, но нет даты акта» — это была разовая доработка
// уже загруженных заявок. Для новой партии нужны все её заявки, поэтому отбор заменён на список шага 0.
&НаСервере
Процедура Шаг3_ЗагрузитьДоговорыИАкты(Партия)

	Валюта_            = Справочники.Валюты.НайтиПоКоду("643");
	ОснКомпания        = Справочники.Контрагенты.ОсновнаяКомпания;
	ЛьготнаяКатегория_ = Справочники.УТП_КатегорииЛьгот.ЛьготнаяКатегория;
	ЗаявкиПартии       = ЗаявкиПоBidID(Партия);

	ТекстЗапроса =
	"ВЫБРАТЬ
	|	bid.BidID КАК BidID,
	|	bid.Dogovor_NN КАК Dogovor_NN,
	|	bid.Dogovor_Date КАК Dogovor_Date,
	|	bid.SocTarif КАК SocTarif,
	|	bid.EvtSrok КАК EvtSrok,
	|	cot.RealAct_NN КАК RealAct_NN,
	|	cot.RealAct_Date КАК RealAct_Date,
	|	cot.CostTotal КАК CostTotal,
	|	evt.Vyp_k_Sel_Date КАК Vyp_k_Sel_Date
	|ИЗ
	|	ВнешнийИсточникДанных.КрымMySQL.Таблица.bid КАК bid
	|		ЛЕВОЕ СОЕДИНЕНИЕ ВнешнийИсточникДанных.КрымMySQL.Таблица.cot КАК cot
	|		ПО bid.BidID = cot.CotID
	|		ЛЕВОЕ СОЕДИНЕНИЕ ВнешнийИсточникДанных.КрымMySQL.Таблица.evt КАК evt
	|		ПО bid.BidID = evt.EvtID
	|ГДЕ
	|	bid.BidID В (&СписокBidID)
	|
	|УПОРЯДОЧИТЬ ПО
	|	BidID";
	ДанныеBID_тз = ВыполнитьЗапросКрымMySQLПорциями(ТекстЗапроса, Партия.ВыгрузитьКолонку("BidID"));

	Сообщить("Заявок в партии: " + Партия.Количество() + ", найдено в КрымMySQL: " + ДанныеBID_тз.Количество());
	Обработано = 0; Ошибок = 0;

	Для Каждого Выборка Из ДанныеBID_тз Цикл // Выборка — строка bid (+ cot, evt)

		ЗаявкаТП = ЗаявкиПартии[Выборка.BidID]; // bid выбраны по BidID партии, поэтому заявка есть всегда

		Попытка
			ЗаявкаОб = ЗаявкаТП.ПолучитьОбъект();

			// Льготная категория
			Если ЗначениеЗаполнено(Выборка.SocTarif) И Выборка.SocTarif > 0 Тогда
				ЗаявкаОб.ЛьготнаяКатегория = ЛьготнаяКатегория_;
			Иначе
				ЗаявкаОб.ЛьготнаяКатегория = Неопределено;
			КонецЕсли;

			// Выполнено к селектору — в документ данных исполнения (шаг 2)
			ДатаВыпКСелектору = ДатаИзИсточника(Выборка.Vyp_k_Sel_Date);
			Если ЗначениеЗаполнено(ЗаявкаОб.ДанныеИсполненияЗаявки) И ЗначениеЗаполнено(ДатаВыпКСелектору) Тогда
				ДанныеИсполненияЗаявки_Об = ЗаявкаОб.ДанныеИсполненияЗаявки.ПолучитьОбъект();
				ДанныеИсполненияЗаявки_Об.ВыполненоКСелектору = ДатаВыпКСелектору;
				ДанныеИсполненияЗаявки_Об.ОбменДанными.Загрузка = Истина;
				ДанныеИсполненияЗаявки_Об.Записать();
			КонецЕсли;

			// Срок договора: с даты договора на EvtSrok дней
			ДатаНачала_    = ?(ЗначениеЗаполнено(Выборка.Dogovor_Date), Выборка.Dogovor_Date, Дата(1, 1, 1));
			ДатаОкончания_ = Дата(1, 1, 1);
			Если ЗначениеЗаполнено(ДатаНачала_) И ЗначениеЗаполнено(Выборка.EvtSrok) Тогда
				ДатаОкончания_ = ДатаНачала_ + Выборка.EvtSrok * 86400;
			КонецЕсли;

			// --- Договор ТП ---
			Если ЗначениеЗаполнено(Выборка.Dogovor_NN) ИЛИ ЗначениеЗаполнено(Выборка.Dogovor_Date) Тогда
				Если ЗначениеЗаполнено(ЗаявкаТП.ДоговорТП) Тогда
					Договор_об = ЗаявкаТП.ДоговорТП.ПолучитьОбъект();
				Иначе
					Договор_об = Справочники.ИБР_Договоры.СоздатьЭлемент();
				КонецЕсли;

				Договор_об.ДатаЗаключения    = ДатаНачала_;
				Договор_об.ДатаНачала        = ДатаНачала_;
				Договор_об.ДатаОкончания     = ДатаОкончания_;
				Договор_об.ВидДоговора       = УТП_Сервер.ВернутьВидДоговораТП_поЗаявке(ЗаявкаОб.Ссылка); // зависит от данных шага 1
				Договор_об.ДокументОснование = ЗаявкаОб.Ссылка;
				Договор_об.Наименование      = " Загружен по " + ЗаявкаОб.Ссылка;
				Договор_об.Валюта            = Валюта_;
				Договор_об.Организация       = ОснКомпания;
				Если ЗначениеЗаполнено(Выборка.Dogovor_NN) Тогда
					Договор_об.Код = СокрЛП(Выборка.Dogovor_NN);
				КонецЕсли;
				Если ТипЗнч(ЗаявкаОб.Заявитель) = Тип("СправочникСсылка.Контрагенты") Тогда
					Договор_об.ОсновнойКонтрагент = ЗаявкаОб.Заявитель; // заявитель может быть строкой
				КонецЕсли;
				Если ЗначениеЗаполнено(Выборка.CostTotal) Тогда
					Договор_об.ОбщаяСумма = Число(Выборка.CostTotal);
				КонецЕсли;

				Договор_об.ОбменДанными.Загрузка = Истина;
				Попытка
					Договор_об.Записать();
					ЗаявкаОб.ДоговорТП = Договор_об.Ссылка;
				Исключение
					Шаг3_ЗаписатьОшибку(Выборка.BidID, ЗаявкаТП, "Договор не записан: " + КраткоеПредставлениеОшибки(ИнформацияОбОшибке()));
				КонецПопытки;

			ИначеЕсли ЗначениеЗаполнено(ЗаявкаТП.ДоговорТП) Тогда
				// В источнике договора нет — удаляем созданный ранее
				ЗаявкаТП.ДоговорТП.ПолучитьОбъект().Удалить();
				ЗаявкаОб.ДоговорТП = Неопределено;
			КонецЕсли;

			// --- Акт ТП ---
			Если ЗначениеЗаполнено(Выборка.RealAct_NN) ИЛИ ЗначениеЗаполнено(Выборка.RealAct_Date) Тогда
				Если ЗначениеЗаполнено(ЗаявкаТП.АктОТехнологическомПрисоединении) Тогда
					ДокументАКТП_об = ЗаявкаТП.АктОТехнологическомПрисоединении.ПолучитьОбъект();
				Иначе
					ДокументАКТП_об = Документы.ЭЭ_АктОТехнологическомПрисоединении.СоздатьДокумент();
				КонецЕсли;

				ДатаАкта_ = ДатаИзИсточника(Выборка.RealAct_Date);
				Если Не ЗначениеЗаполнено(ДатаАкта_) Тогда
					ДатаАкта_ = ДатаОкончания_;
				КонецЕсли;

				Попытка
					ДокументАКТП_об.Номер = Выборка.RealAct_NN;
				Исключение
					Шаг3_ЗаписатьОшибку(Выборка.BidID, ЗаявкаТП, "Номер акта """ + Выборка.RealAct_NN + """ не установлен: "
						+ КраткоеПредставлениеОшибки(ИнформацияОбОшибке()));
				КонецПопытки;

				ДокументАКТП_об.Дата = ДатаАкта_;
				ДокументАКТП_об.Проведен = Истина;
				Попытка
					ДокументАКТП_об.ОбменДанными.Загрузка = Истина;
					ДокументАКТП_об.Записать();
					ЗаявкаОб.АктОТехнологическомПрисоединении = ДокументАКТП_об.Ссылка;
				Исключение
					Шаг3_ЗаписатьОшибку(Выборка.BidID, ЗаявкаТП, "Акт не записан: " + КраткоеПредставлениеОшибки(ИнформацияОбОшибке()));
				КонецПопытки;

			ИначеЕсли ЗначениеЗаполнено(ЗаявкаТП.АктОТехнологическомПрисоединении) Тогда
				// В источнике акта нет — удаляем созданный ранее
				ЗаявкаТП.АктОТехнологическомПрисоединении.ПолучитьОбъект().Удалить();
				ЗаявкаОб.АктОТехнологическомПрисоединении = Неопределено;
			КонецЕсли;

			ЗаявкаОб.ОбменДанными.Загрузка = Истина;
			ЗаявкаОб.Записать();
			Обработано = Обработано + 1;

		Исключение
			Ошибок = Ошибок + 1;
			Шаг3_ЗаписатьОшибку(Выборка.BidID, ЗаявкаТП, ПодробноеПредставлениеОшибки(ИнформацияОбОшибке()));
		КонецПопытки;

	КонецЦикла;

	Сообщить("Обработано заявок: " + Обработано + ", ошибок: " + Ошибок
		+ " (подробности — журнал ""ИсторическиеЗаявки. Договоры и акты"")");

// Дата из внешнего источника: Дата — как есть; строка "ГГГГ-ММ-ДД[...]" — разбирается;
// NULL / пусто / не разбирается — пустая дата.
&НаСервере
Функция ДатаИзИсточника(Значение)

	Если ТипЗнч(Значение) = Тип("Дата") Тогда
		Возврат Значение;
	ИначеЕсли ТипЗнч(Значение) = Тип("Строка") И ЗначениеЗаполнено(Значение) Тогда
		Попытка
			Возврат Дата(СтрЗаменить(Лев(СокрЛП(Значение), 10), "-", ""));
		Исключение
			Возврат Дата(1, 1, 1);
		КонецПопытки;
	КонецЕсли;
	Возврат Дата(1, 1, 1);
