// Загрузка данных исполнения заявок ТП из внешнего источника КрымMySQL в документы УТП_ДанныеИсполненияЗаявкиТП.
//
// Схема связей:
//   ЭЭ_ЗаявкаТП.ИБР_Основание = bid.BidID          (заявки с ЗаявкаПолученаССайта = БазаMySQL)
//   ЭЭ_ЗаявкаТП.Ссылка = УТП_ДанныеИсполненияЗаявкиТП.ЗаявкаТП
//   bid ─(BidID)─ evt / gvt / cot (1:1), bid.IstFinID → istfin
//
// Ограничение платформы: в одном запросе нельзя получать данные из нескольких источников
// («Получение данных из нескольких источников данных недопустимо»). Временная таблица из
// ИБР_ВБО_ОбщегоНазначенияСервер.ВременаяТаблицаЗапроса находится в ИБ, поэтому запрос к КрымMySQL её не видит.
// Связь ИБ ↔ MySQL делается через параметр: список BidID из ИБ передаётся в запрос к MySQL.
//
// Шаги:
//   1. Запрос к ИБ: заявки ЭЭ_ЗаявкаТП из MySQL + существующие документы данных исполнения (ЗаявкиИБ_тз),
//      упорядочены по BidID. КоличествоНаПроверку > 0 — только первые N (отладка).
//   2. Основной пакетный запрос — к КрымMySQL (текст — Запрос_КрымMySQL_УТП_ДанныеИсполненияЗаявкиТП.txt),
//      отбор bid.BidID В (&СписокBidID): [0] шапка, [1] ТЧ Оплаты. Выполняется порциями по РазмерПорции BidID;
//      метка &СписокBidID заменяется в тексте списком чисел (без параметра-массива — у onec нет CREATE TEMPORARY TABLES).
//   3. Шапка переносится одним ЗаполнитьЗначенияСвойств, ЗаявкаТП — из строки ЗаявкиИБ_тз того же BidID,
//      ВидообразующийРеквизит — элемент ИБР_ВидыОбъектов «Данные для отчёта» (вид документа «Данные исполнения заявки ТП»).
//      Существующий документ обновляется, иначе создаётся новый.
//   4. Запись в режиме загрузки: Проведен = Истина, ОбменДанными.Загрузка = Истина, Записать() —
//      документ получает пометку проведения, обработчики ПередЗаписью / ОбработкаПроведения / подписки не выполняются.
//      При КоличествоНаПроверку > 0 обработанные документы выводятся в ТаблицаПротокола (реквизит формы:
//      колонки ЗаявкаТП, ДанныеИсполненияЗаявки).
//   Сортировка везде по BidID: ЗаявкиИБ_тз, шапка MySQL, ТЧ Оплаты.
//
// Порядок параметров: ЗаполнитьЗначенияСвойств(Приёмник, Источник) =
//   ЗаполнитьЗначенияСвойств(ОбъектУТП_ДанныеИсполненияЗаявки, ТекущаяСтрока).

// Параметры:
//   КоличествоНаПроверку - Число - 0 = все заявки; N > 0 = первые N заявок по BidID (для отладки).
//                                  С формы: ЗагрузитьДанныеИсполненияИзКрымMySQL(КоличествоНаПроверку);
//   ДелительТысРуб       - Число - 1 или 1000. Пересчёт единиц для 5 реквизитов, у которых в синониме 1С указаны «тыс.руб»:
//                                  ПервичнаяСтоимостьПИР    <- evt.PirBase_Sum
//                                  СуммаДоговораПИР         <- evt.PirDog_Sum
//                                  СметнаяСтоимостьПроекта  <- evt.ProeSmeta_Sum
//                                  СтоимостьОсновныхФондов  <- evt.OsnFond_Sum
//                                  ВыпадающиеРасходы        <- evt.Others_Sum
//                                  Почему: в TPrLog единицы этих полей MySQL не указаны. Если в MySQL рубли,
//                                  а в 1С тыс.руб, без деления значение в документе будет в 1000 раз больше.
//                                  Пример: evt.PirBase_Sum = 1250000 (1 250 000 руб.)
//                                    ДелительТысРуб = 1000 -> ПервичнаяСтоимостьПИР = 1 250,00 тыс.руб  (верно, если в MySQL рубли)
//                                    ДелительТысРуб = 1    -> ПервичнаяСтоимостьПИР = 1 250 000,00      (верно, если в MySQL уже тыс.руб)
//                                  Как выбрать: сверить 2-3 заявки, где сумма ПИР/смета известна по документам.
//                                  Остальные суммы (ГКЦТ, КУэ, подряд, акт ПИР) в 1С в рублях и не делятся.
//   РазмерПорции         - Число - сколько BidID передавать в один запрос к MySQL (список В (&СписокBidID)).
&НаСервере
Процедура ЗагрузитьДанныеИсполненияИзКрымMySQL(КоличествоНаПроверку = 0, ДелительТысРуб = 1, РазмерПорции = 50) Экспорт
	
	Протокол = Новый Массив;
	Создано = 0; Обновлено = 0; Ошибок = 0; Счетчик = 0;
	
	// Вид документа для ВидообразующийРеквизит — один раз на всю загрузку
	ВидОбъектаУТП = ВидДанныхДляОтчета();
	
	// 1. Заявки ИБ, пришедшие из MySQL
	ЗаявкиИБ_тз = ЗаявкиИБ(КоличествоНаПроверку);
	ВсегоЗаявокВ1С = ЗаявкиИБ_тз.Количество();
	
	// BidID -> строка ЗаявкиИБ_тз. ТаблицаЗначений.Найти() индекс не использует и каждый раз
	// просматривает таблицу целиком (200 000 × 200 000); Соответствие.Получить() — мгновенно.
	ЗаявкиПоBidID = Новый Соответствие;
	Для Каждого СтрокаИБ Из ЗаявкиИБ_тз Цикл
		ЗаявкиПоBidID.Вставить(СтрокаИБ.BidID, СтрокаИБ);
	КонецЦикла;
		
	// 2. Основной запрос к КрымMySQL — порциями по списку BidID
	ТекстЗапросаMySQL = ТекстЗапросаКрымMySQL(); // шаблон: &СписокBidID заменяется кодами для каждой порции
	Запрос = Новый Запрос;
	Запрос.УстановитьПараметр("ДелительТысРуб", ДелительТысРуб);
	
	ВсеBidID = ЗаявкиИБ_тз.ВыгрузитьКолонку("BidID");
	Начало = 0;
	Пока Начало < ВсеBidID.Количество() Цикл
		
		Если КоличествоНаПроверку > 0 И Счетчик >= КоличествоНаПроверку Тогда
			Прервать;
		КонецЕсли;
		
		СписокBidID = Новый Массив;
		Для Индекс = Начало По Мин(Начало + РазмерПорции, ВсеBidID.Количество()) - 1 Цикл
			СписокBidID.Добавить(Формат(ВсеBidID[Индекс], "ЧГ=0; ЧН=0"));
		КонецЦикла;
		Начало = Начало + РазмерПорции;
		
		// Коды — числа, поэтому подставляем их прямо в текст: В (123, 124, ...).
		// Параметр-массив 1С передаёт в MySQL через временную таблицу, а права CREATE TEMPORARY TABLES у onec нет.
		Запрос.Текст = СтрЗаменить(ТекстЗапросаMySQL, "&СписокBidID", СтрСоединить(СписокBidID, ", "));
		Пакет = Запрос.ВыполнитьПакет();
		
		ВыборкаШапка = Пакет[0].Выбрать();
		Оплаты_тз = Пакет[1].Выгрузить();
		Оплаты_тз.Индексы.Добавить("Источник_BidID");
		
		// 3. Заполнение документов
		Пока ВыборкаШапка.Следующий() Цикл
			Если КоличествоНаПроверку > 0 И Счетчик >= КоличествоНаПроверку Тогда
				Прервать;
			КонецЕсли;
			// Заявка ИБ того же BidID: ЗаявкаТП и существующий документ данных исполнения
			СтрокаИБ = ЗаявкиПоBidID.Получить(ВыборкаШапка.BIDID_ЗаявкаТП);
			Если СтрокаИБ = Неопределено Тогда
				Продолжить;
			КонецЕсли;
			Попытка
				Если ЗначениеЗаполнено(СтрокаИБ.ДанныеИсполнения) Тогда
					ОбъектУТП_ДанныеИсполненияЗаявки = СтрокаИБ.ДанныеИсполнения.ПолучитьОбъект();
					Обновлено = Обновлено + 1;
				Иначе
					ОбъектУТП_ДанныеИсполненияЗаявки = Документы.УТП_ДанныеИсполненияЗаявкиТП.СоздатьДокумент();
					ОбъектУТП_ДанныеИсполненияЗаявки.Дата = ТекущаяДатаСеанса();
					Создано = Создано + 1;
				КонецЕсли;
				
				// Шапка. Поля Источник_* и BIDID_ЗаявкаТП в документе отсутствуют и пропускаются.
				ЗаполнитьЗначенияСвойств(ОбъектУТП_ДанныеИсполненияЗаявки, ВыборкаШапка);
				ОбъектУТП_ДанныеИсполненияЗаявки.ЗаявкаТП = СтрокаИБ.Заявка;
				ОбъектУТП_ДанныеИсполненияЗаявки.ВидообразующийРеквизит = ВидОбъектаУТП;
				
				// ТЧ Оплаты — полностью из cot
				ОбъектУТП_ДанныеИсполненияЗаявки.Оплаты.Очистить();
				Для Каждого СтрокаОплаты Из Оплаты_тз.НайтиСтроки(Новый Структура("Источник_BidID", ВыборкаШапка.BIDID_ЗаявкаТП)) Цикл
					ЗаполнитьЗначенияСвойств(ОбъектУТП_ДанныеИсполненияЗаявки.Оплаты.Добавить(), СтрокаОплаты);
				КонецЦикла;
				
				// Запись в режиме загрузки + пометка проведения (ОбработкаПроведения не вызывается)
				ОбъектУТП_ДанныеИсполненияЗаявки.Проведен = Истина;
				ОбъектУТП_ДанныеИсполненияЗаявки.ИБР_Основание = ВыборкаШапка.BIDID_ЗаявкаТП; // = ЭЭ_ЗаявкаТП.ИБР_Основание (BidID)
				ОбъектУТП_ДанныеИсполненияЗаявки.ОбменДанными.Загрузка = Истина;
				Если ОбъектУТП_ДанныеИсполненияЗаявки.ЭтоНовый() И Не ЗначениеЗаполнено(ОбъектУТП_ДанныеИсполненияЗаявки.Номер) Тогда
					ОбъектУТП_ДанныеИсполненияЗаявки.УстановитьНовыйНомер();
				КонецЕсли;
				
				ОбъектУТП_ДанныеИсполненияЗаявки.ИБР_Автор = ПараметрыСеанса.ИБР_ТекущийПользователь;
				ОбъектУТП_ДанныеИсполненияЗаявки.ИБР_ДатаСоздания = ТекущаяДата();
				ОбъектУТП_ДанныеИсполненияЗаявки.ИБР_ДолжностноеЛицо = ПараметрыСеанса.ИБР_ДолжностьПользователяПоУмолчанию;
				ОбъектУТП_ДанныеИсполненияЗаявки.Записать();
				
				// Обратная ссылка в заявке — перезаписываем ЭЭ_ЗаявкаТП только если ссылка изменилась
				// (при повторной загрузке она уже стоит, и лишние 200 000 записей заявок не нужны)
				Если СтрокаИБ.ДанныеИсполненияВЗаявке <> ОбъектУТП_ДанныеИсполненияЗаявки.Ссылка Тогда
					ЭЭ_ЗаявкаТП_об = СтрокаИБ.Заявка.ПолучитьОбъект();
					ЭЭ_ЗаявкаТП_об.ДанныеИсполненияЗаявки = ОбъектУТП_ДанныеИсполненияЗаявки.Ссылка;
					ЭЭ_ЗаявкаТП_об.ОбменДанными.Загрузка = Истина;
					ЭЭ_ЗаявкаТП_об.Записать();
				КонецЕсли;
				
				Счетчик = Счетчик + 1;
				Если КоличествоНаПроверку > 0 И Счетчик <= КоличествоНаПроверку Тогда
					НС = ТаблицаПротокола.Добавить();
					НС.ЗаявкаТП = ОбъектУТП_ДанныеИсполненияЗаявки.ЗаявкаТП;
					НС.ДанныеИсполненияЗаявки = ОбъектУТП_ДанныеИсполненияЗаявки.Ссылка;
				КонецЕсли;
			Исключение
				Ошибок = Ошибок + 1;
			КонецПопытки;
			
		КонецЦикла;
		
	КонецЦикла;
	Сообщить("Ошибок - " + Ошибок);
	//НайденоВMySQL = ВыборкаШапка.Количество();
	//ИтогТекст = СтрШаблон(?(КоличествоНаПроверку > 0, "[ОТЛАДКА: первые " + Формат(КоличествоНаПроверку, "ЧГ=0") + "] ", "")
	//	+ "Загрузка КрымMySQL: заявок MySQL в 1С %1, найдено в bid %2 (создано %3, обновлено %4), нет в bid %5, ошибок %6",
	//	ВсегоЗаявокВ1С, НайденоВMySQL, Создано, Обновлено, ВсегоЗаявокВ1С - НайденоВMySQL, Ошибок);
	//Протокол.Вставить(0, ИтогТекст);

	//	Метаданные.Документы.УТП_ДанныеИсполненияЗаявкиТП, , СтрСоединить(Протокол, Символы.ПС));

// Колонки: BidID (= ИБР_Основание), Заявка, КоличествоЗаявок, ДанныеИсполнения.
// Дубли ИБР_Основание схлопываются в одну строку (МАКСИМУМ), их количество — в КоличествоЗаявок.
// КоличествоНаПроверку > 0 — только первые N по BidID (ПЕРВЫЕ не принимает параметр, число подставляется в текст).
&НаСервере
Функция ЗаявкиИБ(КоличествоНаПроверку = 0)

	Запрос = Новый Запрос;
	Запрос.Текст =
	"ВЫБРАТЬ
	|	ЭЭ_ЗаявкаТП.ИБР_Основание КАК BidID,
	|	МАКСИМУМ(ЭЭ_ЗаявкаТП.Ссылка) КАК Заявка,
	|	КОЛИЧЕСТВО(РАЗЛИЧНЫЕ ЭЭ_ЗаявкаТП.Ссылка) КАК КоличествоЗаявок
	|ПОМЕСТИТЬ ЗаявкиMySQL
	|ИЗ
	|	Документ.ЭЭ_ЗаявкаТП КАК ЭЭ_ЗаявкаТП
	|ГДЕ
	|	НЕ ЭЭ_ЗаявкаТП.ПометкаУдаления
	|	И ЭЭ_ЗаявкаТП.ЗаявкаПолученаССайта = &БазаMySQL
	|
	|СГРУППИРОВАТЬ ПО
	|	ЭЭ_ЗаявкаТП.ИБР_Основание
	|;
	|
	|////////////////////////////////////////////////////////////////////////////////
	|ВЫБРАТЬ %ПЕРВЫЕ%
	|	ЗаявкиMySQL.BidID КАК BidID,
	|	ЗаявкиMySQL.Заявка КАК Заявка,
	|	ЗаявкиMySQL.КоличествоЗаявок КАК КоличествоЗаявок,
	|	ЕСТЬNULL(МАКСИМУМ(УТП_ДанныеИсполненияЗаявкиТП.Ссылка), ЗНАЧЕНИЕ(Документ.УТП_ДанныеИсполненияЗаявкиТП.ПустаяСсылка)) КАК ДанныеИсполнения,
	|	ЗаявкиMySQL.Заявка.ДанныеИсполненияЗаявки КАК ДанныеИсполненияВЗаявке
	|ИЗ
	|	ЗаявкиMySQL КАК ЗаявкиMySQL
	|		ЛЕВОЕ СОЕДИНЕНИЕ Документ.УТП_ДанныеИсполненияЗаявкиТП КАК УТП_ДанныеИсполненияЗаявкиТП
	|		ПО (УТП_ДанныеИсполненияЗаявкиТП.ЗаявкаТП = ЗаявкиMySQL.Заявка)
	|			И (НЕ УТП_ДанныеИсполненияЗаявкиТП.ПометкаУдаления)
	|
	|СГРУППИРОВАТЬ ПО
	|	ЗаявкиMySQL.BidID,
	|	ЗаявкиMySQL.Заявка,
	|	ЗаявкиMySQL.КоличествоЗаявок,
	|	ЗаявкиMySQL.Заявка.ДанныеИсполненияЗаявки
	|
	|УПОРЯДОЧИТЬ ПО
	|	ЗаявкиMySQL.BidID";
	Запрос.Текст = СтрЗаменить(Запрос.Текст, "%ПЕРВЫЕ%",
		?(КоличествоНаПроверку > 0, "ПЕРВЫЕ " + Формат(КоличествоНаПроверку, "ЧГ=0"), ""));
	Запрос.УстановитьПараметр("БазаMySQL", Справочники.УТП_ИсточникиЗаявок.БазаMySQL);

	Возврат Запрос.Выполнить().Выгрузить();
